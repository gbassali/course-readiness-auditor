# Assignment 2 — Grading Rubric

**Assessment ID:** `assignment-2`

| Criterion | Weight | Expectations |
|---|---:|---|
| Functional correctness | 30% | Required endpoints and registration rules work as described. |
| Relational schema design | 25% | Tables, relationships, keys, and constraints are appropriate and normalized. |
| API design and validation | 15% | Endpoints are clear and invalid requests return consistent responses. |
| Automated test coverage | 15% | Automated tests cover the main service operations, validation rules, and failure cases. |
| Documentation and setup | 10% | The README clearly explains how to configure and run the service. |
| Code organization | 5% | Responsibilities are separated and the code is reasonably maintainable. |

## Grading Notes

Markers should apply the rubric consistently and include a brief explanation for major deductions.
